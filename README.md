# Дизайн neurology-club.ru — макеты для верстальщиков

> **Живая версия:** https://neuro-club-mockups.vercel.app/ · карта страниц — `navigation.html`.
> Статический HTML/CSS/JS без сборки: открыть `index.html` через локальный сервер (см. ниже).

Задача по ТЗ: «подготовить дизайн для старой части как у новой части сайта; верстальщики клиента
обновят на его основе главную страницу и страницы разделов». Разделы и внутренние страницы — по
списку клиента (2026-10-03).

## Как открыть

```bash
python3 -m http.server 4173   # из корня репозитория
# http://127.0.0.1:4173/
```

Шрифты — Google Fonts, картинки — локальные копии из `assets/img` (сжатые с сайта клуба).

## Дизайн-система ai (с 23.10)

Клиенту понравился ai-портал — макеты клуба переведены на его систему, чтобы клуб и ai читались как **один сайт**:

- **Каркас** (`assets/shell.js`, 05.11 — как на ai после макета клиента 31.10): сверху белая строка — цветной
  логотип (`assets/club-logo.png`), разделы тёмно-синим, синяя «Войти» и белая «Регистрация»; ниже синее полотно
  с узором из точек — на главной девиз и крупный белый поиск, на остальных только поиск; снизу белая дуга.
  Слева узкая полоса значков (Главная, Нозологии, Практика, Мировая, Видео, Учиться, Клуб, Пациентам) заходит
  на дугу; у групп панель с пунктами выезжает при наведении (тач/клавиатура — по нажатию). При прокрутке сверху
  выезжает узкая белая полоса: знак, поиск, вход. На синем — «нейронный след» от курсора и сеть по клику
  (только мышь, без анимации при reduced-motion). Подвал с синим баннером дайджеста. Телефон: логотип, вход и
  меню; в синей полосе поиск и разделы строкой с прокруткой; синее меню выезжает слева.
- **Токены и компоненты** (`assets/ai.css`, подключён после `club.css`): Manrope везде, синий клуба `#1A76DD`
  для действий/рубрик/ссылок, серые карточки `#F6F7F9`, радиусы 22/28, кнопки-«таблетки», шапки разделов —
  голубые плашки (как `PageHero` на ai), бывшие тёмные полосы — синие плашки с узором.
- Прежняя «бумажная» оболочка — `assets/shell-paper.js`; раздел «Принципы» ниже описывает её (история).

## Принципы

**Одна система с ai.neurology-club.ru, но не копия.** Общие: бумага, краска, шрифты, меню слева
(ТЗ, п. 5: меню единое). Свои у клуба: тёмно-синие полосы для журнала, программ и перехода на ai-часть,
портреты экспертов, обложки «Вестника».

- **Бумага, а не «сайт»:** фон `#FAFAF9`, текст `#16171A`, волосяные линии `#E4E4E0`. **Теней нет** —
  глубина только из смены фона и линий (исключение — обложки журнала).
- **Шрифты:** Source Serif 4 — заголовки и длинный текст; IBM Plex Sans — интерфейс и подписи прописными
  (`СТАТЬЯ · 29.09 · 7 МИН`: 11px, 500, разрядка .045em, табличные цифры); IBM Plex Mono — только даты, номера,
  таймкоды и клавиши. Других шрифтов не добавлять. (11.10: моно прописными с разрядкой .08em выглядел грубо.)
- **Межстрочный интервал в подписях** — 1.35; короткие подписи под цифрами — в одну строку (`white-space: nowrap`),
  колонки по ширине содержимого: перенос с большим интервалом выглядит неаккуратно.
- **Цвет по ролям** (не менять роли):
  - ультрамарин `#062A86` — рубрики, активный пункт, ссылки;
  - кобальт клуба `#1A76DD` — **только** кнопки действия (Войти, Регистрация, Скачать PDF, Продолжить);
  - ночной `#0D1530` — тёмные полосы: «Вестник», программы, переход на ai-часть, карточка участника в ЛК;
  - красный `#D12B2B` — только индикатор «сегодня/live».
- **Форма:** кнопки и поля — радиус 3px; карточки и картинки — 8px; тёмные полосы — 14px.
- **Отказались** от оранжевых кнопок-«мазков», голубых плашек, хештегов, круглых фото, разномастных
  логотипов партнёров (теперь в сетке, в ч/б, цвет — при наведении).

## Компоненты (классы в `assets/club.css`)

`label` (моно-подпись) · `section-head` (заголовок секции с линией) · `card` / `row-card` / `list-item` ·
`media` + `ratio-*` (картинка с фиксированной пропорцией) · `band` (тёмная полоса) · `portrait` (эксперт) ·
`tabs` / `toolbar` (фильтры текстом, без плашек) · `page-head` (шапка раздела со счётчиком) ·
`article` (колонка текста 680 + поля 300) · `prose` · `table` · `notice` («для специалистов») ·
`cover` (обложка журнала) · `toc` (оглавление на тёмном) · `journal` (издание в Med-library) ·
`panel` / `form-grid` / `toggle-row` / `switch` (ЛК).

## Картинки — важно для скорости

- Оригиналы на сайте клуба весят **9–11 МБ** (например, обложки статей в `/upload/iblock/…`): главная
  открывается секундами. Перед публикацией сжимать до 1400 px по длинной стороне, JPEG/WebP ~80%
  (в макетах — 90–300 КБ).
- **Фото экспертов** сейчас загружены уже вырезанными кругом; в макете они кадрируются внутри круга
  (`.portrait img { transform: scale(1.42) }`). Для новых фото — квадрат без обрезки, без масштаба.
- **Постеры программ** — фирменные визуалы со своим текстом: показывать целиком (16:9), не обрезать
  и не накладывать на них заголовки.
- Портреты — чёрно-белые, цвет при наведении: так разные фото выглядят единым рядом.

## Что в макетах условно

Тексты и структура взяты с сайта клуба (статьи, эксперты, видео, программы, выпуски «Вестника»), но
**числа и часть подробностей — для вёрстки**: счётчики разделов (146 лекций, 64 шпаргалки…), состав
модулей и баллы НМО программ, статистика эксперта, оглавление лекции, данные в ЛК, цитата редактора
выпуска. Текст статьи `article.html` после первого абзаца написан для вёрстки (у клуба статья закрыта для
гостей) — на сайте подставляется настоящий текст. На сайте — реальные данные из Битрикса.

Виджеты «Сегодня в неврологии», «Новости» и «Календарь событий» на главной — из ai-части (ТЗ, п. 3):
ai.neurology-club.ru отдаст их JSON-фидом или встраиваемым блоком (делаем отдельно).

## Меню (11.10, утверждено)

Одно меню для клуба и ai по карте `navigation.html`: Главная · Клиническая практика · Мировая неврология (ai) ·
Смотреть · Учиться · Клуб, акцентная кнопка «Навигация по нозологиям», «Пациентам» — отдельно внизу. Пункты ai помечены
«AI» и открывают ai.neurology-club.ru. Данные меню — `MENU` в `assets/shell.js`; в Битриксе — компонент меню с теми же группами.
«Видео» — вкладки «Лекции клуба / Мировые конференции / Подкасты · архив»; «Шпаргалки и инфографика» — вкладки.

## Обновления 11.10 (за ai-частью)

- **Окно поиска (⌘K)** — клик по строке поиска в шапке или ⌘K (`assets/shell.js`, классы `sd-*`): строка запроса
  антиквой, результаты клуба и ai вместе с пометкой источника («КЛУБ» / «AI»), выбранный пункт — полоса ультрамарином,
  совпадения подчёркнуты ультрамарином. Так же устроен поиск на ai.neurology-club.ru.
- **«Коротко»** на странице статьи (`article.html`, класс `facts`): тип материала, нозология, для кого, время чтения.
- **«Сегодня в неврологии»**: в шапке блока — «+N за сутки», в подписи — уровень доказательности (РКИ, метаанализ,
  когортное…). Настоящий виджет отдаёт это сам (`/api/widgets/today`, поле `today` и `meta`).
- **Телефон**: в шапке знак клуба и кнопка меню, левое меню выезжает поверх страницы; строка поиска сворачивается в
  кнопку, «Регистрация» — со страницы входа.
